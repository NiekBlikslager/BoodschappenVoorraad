BOODSCHAPPENVOORRAAD OP IPHONE

Deze map is een Progressive Web App (PWA). De bestanden moeten samen op een HTTPS-website staan.

Aanbevolen gratis publicatie:
1. Maak een gratis GitHub-account en een nieuwe repository, bijvoorbeeld boodschappenvoorraad.
2. Upload alle bestanden uit deze ZIP naar de hoofdmap van de repository.
3. Open Settings > Pages.
4. Kies Deploy from a branch, branch main, map /(root), en kies Save.
5. Open de gepubliceerde HTTPS-link in Safari op de iPhone.
6. Tik op Delen > Zet op beginscherm en schakel Open als webapp in.

Reservekopie:
- Open Beheer > Reservekopie maken.
- Kies Bewaar in Bestanden en selecteer iCloud Drive.
- Terugzetten kan via Beheer > Reservekopie terugzetten.

Belangrijk:
- De dagelijkse data staat lokaal op de iPhone voor snel en offline gebruik.
- Het JSON-backupbestand in iCloud Drive beschermt tegen het wissen van browser-/websitegegevens.
- Een losse HTML vanuit iCloud Drive is niet voldoende voor betrouwbare installatie als webapp; hosting via HTTPS is nodig voor manifest en offline service worker.
